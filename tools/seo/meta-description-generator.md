# Meta Description Generator

AI-powered meta description generator.

**Category:** [SEO](../seo.md) · **Badge:** SEO

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-description-generator](https://app.marketingtool.pro/tools/meta-description-generator)
* **iOS / Android app** — open the **Tools** tab and search “Meta Description Generator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Page Title | text | ✅ |
| Page Content Summary | textarea | ✅ |
| Target Keyword | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Meta Description Generator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
