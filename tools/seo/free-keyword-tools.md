# Free Keyword Tools

AI-powered free keyword tools.

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/free-keyword-tools](https://app.marketingtool.pro/tools/free-keyword-tools)
* **iOS / Android app** — open the **Tools** tab and search “Free Keyword Tools”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Seed Keyword | text | ✅ |
| Target Country | select — US, UK, India, Australia, Canada, Global | optional |
| Language | select — English, Spanish, French, German, Hindi | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Technical**, **Content**, **Rankings**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Free Keyword Tools** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
