# Internal Linking Suggestions

AI-powered internal linking suggestions.

**Category:** [SEO](../seo.md) · **Badge:** SEO

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/internal-linking-suggestions](https://app.marketingtool.pro/tools/internal-linking-suggestions)
* **iOS / Android app** — open the **Tools** tab and search “Internal Linking Suggestions”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Page URL | text | ✅ |
| Sitemap URL | text | optional |
| Max Suggestions | select — 5, 10, 20, 50 | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Configure**, **Generate**, **Results**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Internal Linking Suggestions** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
