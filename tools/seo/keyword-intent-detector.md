# Keyword Intent Detector

AI-powered keyword intent detector.

**Category:** [SEO](../seo.md) · **Badge:** SEO

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/keyword-intent-detector](https://app.marketingtool.pro/tools/keyword-intent-detector)
* **iOS / Android app** — open the **Tools** tab and search “Keyword Intent Detector”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Keywords | textarea | ✅ |
| Output Format | select — Table, JSON, CSV | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Technical**, **Content**, **Rankings**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Keyword Intent Detector** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
