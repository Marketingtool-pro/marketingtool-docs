# Serp Analyzer

AI-powered serp analyzer.

**Category:** [SEO](../seo.md) · **Badge:** SEO

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/serp-analyzer](https://app.marketingtool.pro/tools/serp-analyzer)
* **iOS / Android app** — open the **Tools** tab and search “Serp Analyzer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Target Keyword | text | ✅ |
| Country | select — US, UK, India, Australia, Canada, Global | optional |
| Analysis Depth | select — Top 5, Top 10, Top 20 | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Technical**, **Content**, **Rankings**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Serp Analyzer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
