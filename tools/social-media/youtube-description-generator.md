# Youtube Description Generator

AI-powered youtube description generator.

**Category:** [Social Media & Channels](../social-media.md) · **Badge:** YouTube

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/youtube-description-generator](https://app.marketingtool.pro/tools/youtube-description-generator)
* **iOS / Android app** — open the **Tools** tab and search “Youtube Description Generator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |
| Video Topic | text | optional |
| Video Duration | select — Short (<1 min), Medium (1-5 min), Long (5-15 min), Extended (15+ min) | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Writing**, **Editing**, **Publish**.

## Tips for best results

* **Describe Video Content** — Summarize what the video covers for relevant titles.
* **Include Keywords** — Add search terms viewers would use to find your video.
* **State Your Channel Niche** — Mention your channel topic for consistent branding.

## How to run it

1. Open **Youtube Description Generator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
