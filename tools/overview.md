## How every tool works

1. **Choose a tool** from a category below (or search by name).
2. **Fill in the inputs** — each tool asks only for what it needs.
3. **Generate** — the AI produces a complete, structured result page.
4. **Use it** — copy sections, or on desktop use **Download All** to grab every asset at once.

Every run is saved to your history so you can revisit and iterate.
