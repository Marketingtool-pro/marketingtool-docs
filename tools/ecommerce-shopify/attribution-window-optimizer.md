# Attribution Window Optimizer

Helps set optimal attribution windows across Meta, Google, and TikTok with privacy-first tracking and incrementality testing.

**Category:** [E-commerce & Shopify](../ecommerce-shopify.md) · **Badge:** E-commerce

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/attribution-window-optimizer](https://app.marketingtool.pro/tools/attribution-window-optimizer)
* **iOS / Android app** — open the **Tools** tab and search “Attribution Window Optimizer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |
| Store / Brand Name | text | optional |
| Ad Platforms Used | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Windows**, **Privacy**, **Testing**.

## Tips for best results

* **Current Windows** — Share your current attribution settings per platform.
* **Purchase Cycle** — How long does a typical buyer take to decide?
* **Privacy Setup** — Are you using CAPI, server-side tracking, or cookies?

## How to run it

1. Open **Attribution Window Optimizer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
