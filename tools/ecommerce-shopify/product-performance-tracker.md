# Product Performance Tracker

AI-powered product performance tracker.

**Category:** [E-commerce & Shopify](../ecommerce-shopify.md) · **Badge:** E-commerce

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/product-performance-tracker](https://app.marketingtool.pro/tools/product-performance-tracker)
* **iOS / Android app** — open the **Tools** tab and search “Product Performance Tracker”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |
| Product/Brand Name | text | optional |
| Target Market | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Metrics**, **Insights**, **Export**.

## Tips for best results

* **Specify Time Range** — Define the date range for your analysis period.
* **List Key Metrics** — Name the KPIs you care about most.
* **Include Benchmarks** — Add industry benchmarks for comparison context.

## How to run it

1. Open **Product Performance Tracker** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
