# Customer Lifetime Value Calculator

Calculates and predicts CLV per customer segment using purchase history, then recommends retention strategies to maximize it.

**Category:** [E-commerce & Shopify](../ecommerce-shopify.md) · **Badge:** E-commerce

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/customer-lifetime-value-calculator](https://app.marketingtool.pro/tools/customer-lifetime-value-calculator)
* **iOS / Android app** — open the **Tools** tab and search “Customer Lifetime Value Calculator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |
| Store / Brand Name | text | optional |
| Average Order Value | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Segments**, **Retention**, **Forecast**.

## Tips for best results

* **Average Order Value** — Share your AOV for accurate CLV calculation.
* **Purchase Frequency** — How often does a typical customer buy per year?
* **Customer Lifespan** — Estimate how long customers stay active.

## How to run it

1. Open **Customer Lifetime Value Calculator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
