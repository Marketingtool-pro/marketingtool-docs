# Looker Studio Report Builder

Automate your PPC reporting with professional Looker Studio templates. Pre-built dashboards with KPI scorecards, trend charts, and campaign breakdowns that update automatically.

**Category:** [Analytics, ROI & Attribution](../analytics-roi.md) · **Badge:** Analytics

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/data-studio-reporting](https://app.marketingtool.pro/tools/data-studio-reporting)
* **iOS / Android app** — open the **Tools** tab and search “Looker Studio Report Builder”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Report Requirements | textarea | ✅ |
| Report Type | select — Monthly Performance, Weekly Dashboard, Campaign Deep-Dive, Executive Summary, ROI Report | ✅ |
| Key Metrics | text | optional |
| Data Source | select — Google Ads Only, Google Ads + Analytics, Multi-Platform, Google Ads + Search Console | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Metrics**, **Layout**, **Export**.

## Tips for best results

* **Pick Key KPIs** — Choose 5-8 core metrics that matter most to stakeholders.
* **Add Date Ranges** — Include comparison periods (this month vs last month) for context.
* **Segment by Campaign** — Break down data by campaign type for actionable insights.

## How to run it

1. Open **Looker Studio Report Builder** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
