# Performance Monitoring Dashboard

Stay informed on big trends and small details. Centralized dashboard to monitor all PPC accounts with KPI tracking, anomaly detection, and trend analysis.

**Category:** [Analytics, ROI & Attribution](../analytics-roi.md) · **Badge:** Analytics

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-performance-monitoring-tools](https://app.marketingtool.pro/tools/ppc-performance-monitoring-tools)
* **iOS / Android app** — open the **Tools** tab and search “Performance Monitoring Dashboard”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Monitoring Needs | textarea | ✅ |
| Number of Accounts | number | optional |
| Report Frequency | select — Daily Summary, Weekly Report, Monthly Report, Real-time Alerts | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **KPIs**, **Anomalies**, **Trends**.

## Tips for best results

* **Define Core KPIs** — Pick 3-5 metrics that align with your business goals.
* **Set Comparison Periods** — Compare week-over-week and month-over-month for context.
* **Include All Accounts** — Monitor all ad accounts in one view for efficiency.

## How to run it

1. Open **Performance Monitoring Dashboard** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
