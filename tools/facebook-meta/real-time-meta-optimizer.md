# Real Time Meta Optimizer

Real-time Facebook ad optimization engine that continuously monitors campaign performance and makes instant adjustments to bids, budgets, and audience targeting — responding to market changes in seconds, not hours.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/real-time-meta-optimizer](https://app.marketingtool.pro/tools/real-time-meta-optimizer)
* **iOS / Android app** — open the **Tools** tab and search “Real Time Meta Optimizer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Campaign or Ad Account ID | textarea | ✅ |
| Optimization Speed | select — Conservative (Hourly), Standard (15-min intervals), Aggressive (Real-time) | optional |
| Target Metric | select — ROAS, CPA, CTR, CPM, Conversion Rate | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Set performance thresholds** — Define clear ROAS floors and CPA ceilings so the optimizer knows exactly when to intervene.
* **Enable auto-scaling** — Allow the optimizer to increase budgets on winning campaigns during peak conversion windows.
* **Review optimization logs** — Check what changes were made automatically each day to build trust and refine parameters.

## How to run it

1. Open **Real Time Meta Optimizer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
