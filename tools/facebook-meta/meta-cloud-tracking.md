# Meta Cloud Tracking

Server-side tracking solution that restores accurate conversion data lost after iOS 14.5+ privacy updates. See approximately 20% more conversions in Meta Ads Manager with real-time event transmission and zero-maintenance cloud infrastructure.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-cloud-tracking](https://app.marketingtool.pro/tools/meta-cloud-tracking)
* **iOS / Android app** — open the **Tools** tab and search “Meta Cloud Tracking”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Website URL | text | ✅ |
| E-commerce Platform | select — Shopify, WooCommerce, Magento, BigCommerce, Custom/Other | optional |
| Facebook Pixel ID | text | optional |

## Tips for best results

* **No coding required** — Cloud tracking installs in 1-2 days with zero technical setup on your end.
* **Works alongside Pixel** — Runs seamlessly with your existing Facebook Pixel for dual reporting in both MCT Dashboard and Ads Manager.
* **Recover lost data** — Most advertisers see ~20% more conversion data after enabling server-side tracking.

## How to run it

1. Open **Meta Cloud Tracking** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
