# Meta Custom Automation

Build personalized Facebook ad automation workflows from 300+ metrics. Create sophisticated rules that automatically scale winners, pause losers, and optimize budgets — like a trained media buyer working 24/7.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-custom-automation](https://app.marketingtool.pro/tools/meta-custom-automation)
* **iOS / Android app** — open the **Tools** tab and search “Meta Custom Automation”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| What to Automate | textarea | ✅ |
| Trigger Condition | select — Performance Threshold, Schedule-Based, Budget Limit, Frequency Cap, Custom Combination | optional |
| Automation Action | select — Pause Ad/Ad Set, Increase Budget, Decrease Budget, Change Bid, Send Alert, Multiple Actions | optional |

## Tips for best results

* **Start simple** — Begin with one rule (pause ads below ROAS threshold) before building complex multi-condition workflows.
* **Use 300+ metrics** — Combine any metrics — ROAS + frequency + CPM — to create rules unique to your business model.
* **Schedule for real-time** — Set automations to trigger based on live performance data for fastest response to changes.

## How to run it

1. Open **Meta Custom Automation** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
