# Meta Conversions API Setup

Set up and optimize Meta Conversions API (CAPI) for server-side event tracking. Restore attribution accuracy lost after iOS 14.5+ privacy changes and see 20-30% more conversion data in Ads Manager.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-conversions-api](https://app.marketingtool.pro/tools/meta-conversions-api)
* **iOS / Android app** — open the **Tools** tab and search “Meta Conversions API Setup”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Website URL or Pixel ID | textarea | ✅ |
| Website Platform | select — Shopify, WooCommerce, WordPress, Custom/Other, Magento, BigCommerce | optional |
| Events to Track | select — All Standard Events, Purchase + AddToCart + Lead, Custom Events Only, Full E-commerce Funnel | optional |

## Tips for best results

* **Pair with Pixel** — Run both browser Pixel and server-side CAPI together for maximum event coverage and deduplication.
* **Track key events** — Prioritize Purchase, AddToCart, InitiateCheckout, and Lead events for the highest optimization impact.
* **Monitor event match quality** — Aim for an Event Match Quality score of 6+ in Events Manager for best attribution accuracy.

## How to run it

1. Open **Meta Conversions API Setup** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
