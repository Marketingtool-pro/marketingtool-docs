# Ad Set Storyline

Track every change made to your Facebook ad sets and see exactly how each modification impacts performance. Monitor team actions, automation triggers, and KPI shifts with color-coded analytics.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ad-set-storyline](https://app.marketingtool.pro/tools/ad-set-storyline)
* **iOS / Android app** — open the **Tools** tab and search “Ad Set Storyline”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Set ID or Campaign URL | textarea | ✅ |
| Account Type | select — E-commerce, Lead Generation, App Installs | optional |
| Analysis Timeframe | select — Last 7 days, Last 14 days, Last 30 days, Last 60 days | optional |

## Tips for best results

* **Monitor team changes** — See which team members made changes, when they occurred, and how they affected performance.
* **Audit automations** — Review all actions triggered by automation rules to identify which ones need adjustment.
* **Use color coding** — Green highlights strong metrics, red flags underperforming figures for rapid issue identification.

## How to run it

1. Open **Ad Set Storyline** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
