# Meta Attribution Tool

Multi-touch attribution modeling for Meta ads that tracks the full customer journey from first ad impression to final purchase. Understand which campaigns, ad sets, and creatives truly drive revenue.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-attribution-tool](https://app.marketingtool.pro/tools/meta-attribution-tool)
* **iOS / Android app** — open the **Tools** tab and search “Meta Attribution Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account ID | text | ✅ |
| Attribution Model | select — Last Click, First Click, Linear, Time Decay, Position-Based, Data-Driven | optional |
| Attribution Window | select — 1-day click, 7-day click, 7-day click + 1-day view, 28-day click + 1-day view | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Look beyond last-click** — Multi-touch attribution reveals the true value of awareness campaigns that assist conversions downstream.
* **Compare models** — Test different attribution models (first-touch, last-touch, linear, time-decay) to find the most accurate one.
* **Extend windows** — Use 7-day click + 1-day view attribution windows for most e-commerce, 28-day for high-consideration purchases.

## How to run it

1. Open **Meta Attribution Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
