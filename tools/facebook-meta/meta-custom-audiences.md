# Meta Custom Audiences Builder

Build high-converting Facebook Custom Audiences from website visitors, customer lists, app users, and engagement data. Create layered audience segments for precise retargeting across Meta platforms.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-custom-audiences](https://app.marketingtool.pro/tools/meta-custom-audiences)
* **iOS / Android app** — open the **Tools** tab and search “Meta Custom Audiences Builder”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Audience Source | select — Website Visitors, Customer List (Email/Phone), App Activity, Video Viewers, Page/Profile Engagement, Lead Form Openers | ✅ |
| Time Window | select — Last 7 days, Last 14 days, Last 30 days, Last 60 days, Last 90 days, Last 180 days | optional |
| Audience Name | text | optional |

## Tips for best results

* **Layer audiences** — Combine website visitors + email lists + engagement data for ultra-precise retargeting segments.
* **Exclude purchasers** — Always exclude recent buyers from prospecting campaigns to avoid wasting budget on converted users.
* **Use time windows** — Create audiences based on recency — 7-day visitors convert better than 180-day visitors.

## How to run it

1. Open **Meta Custom Audiences Builder** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
