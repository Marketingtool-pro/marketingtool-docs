# Facebook Performance Dashboard

Real-time Facebook performance dashboard that consolidates campaign metrics, audience insights, and creative analytics into live, always-updated visualizations — replacing manual spreadsheets entirely.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/facebook-performance-dashboard](https://app.marketingtool.pro/tools/facebook-performance-dashboard)
* **iOS / Android app** — open the **Tools** tab and search “Facebook Performance Dashboard”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account ID | text | ✅ |
| Dashboard View | select — Executive Summary, Campaign Deep Dive, Creative Performance, Audience Analysis | optional |
| Data Refresh Rate | select — Real-time, Hourly, Daily | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Pin key metrics** — Keep ROAS, CPA, and daily spend visible at the top of your dashboard for instant health checks.
* **Compare periods** — Use period-over-period comparisons to spot trends — this week vs last week, this month vs last month.
* **Share with stakeholders** — Generate shareable dashboard links for clients and team members who need read-only access.

## How to run it

1. Open **Facebook Performance Dashboard** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
