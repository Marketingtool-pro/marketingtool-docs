# Ads Manager 2.0

Next-generation Facebook ads management with unified performance dashboards, bulk asset editing, AI-powered bidding optimization, and real-time ROAS trend tracking in one centralized platform.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-ads-manager-2](https://app.marketingtool.pro/tools/meta-ads-manager-2)
* **iOS / Android app** — open the **Tools** tab and search “Ads Manager 2.0”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account ID | text | ✅ |
| Dashboard View | select — Campaign Level, Ad Set Level, Ad Level, All Assets | optional |
| Primary KPI | select — ROAS, CPA, CTR, CPM, Conversion Rate | optional |

## Tips for best results

* **Bulk edit assets** — Apply percentage-based budget changes across multiple ad sets simultaneously with one click.
* **Track ROAS trends** — Use real-time graphs to spot performance changes instead of relying on historical averages.
* **Monitor all changes** — Track modifications by automation and team members while seeing immediate performance impacts.

## How to run it

1. Open **Ads Manager 2.0** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
