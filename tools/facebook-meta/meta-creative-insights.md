# Meta Creative Insights

AI-powered creative analytics that unifies billions of data points to identify which Facebook and Instagram ad creatives generate the highest revenue, detect ad fatigue, and recommend creative direction.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-creative-insights](https://app.marketingtool.pro/tools/meta-creative-insights)
* **iOS / Android app** — open the **Tools** tab and search “Meta Creative Insights”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account ID or Creative URL | textarea | ✅ |
| Analysis Scope | select — All Creatives, Top Performers Only, Underperformers, Fatigued Creatives | optional |
| Creative Format | select — All Formats, Images Only, Videos Only, Carousels Only, Stories/Reels | optional |

## Tips for best results

* **Watch for fatigue** — Monitor creative performance trends over time — declining CTR signals it's time to refresh.
* **Use AI visual tags** — AI automatically labels creative elements (people, colors, objects) so you can correlate visuals with performance.
* **Segment by audience** — Discover which creatives perform best with specific audience segments for targeted scaling.

## How to run it

1. Open **Meta Creative Insights** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
