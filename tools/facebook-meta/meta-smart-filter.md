# Meta Smart Filter

Advanced filtering system for Facebook campaigns that lets you slice performance data by any combination of metrics, funnel stages, ad types, and custom parameters to instantly find what's working and what's not.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-smart-filter](https://app.marketingtool.pro/tools/meta-smart-filter)
* **iOS / Android app** — open the **Tools** tab and search “Meta Smart Filter”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account ID | text | ✅ |
| Filter Category | select — Performance Metrics, Funnel Stage, Ad Format, Audience Type, Custom Combination | optional |
| Performance Threshold | select — Top 10% Performers, Above Average, Below Average, Bottom 10% (Losers) | optional |

## Tips for best results

* **Save filter presets** — Create saved filters for common views — like 'High ROAS ads' or 'Fatigued creatives' — for instant access.
* **Combine conditions** — Stack multiple filters (ROAS > 3x AND Spend > $100 AND Frequency < 3) for precise data slicing.
* **Filter by funnel stage** — Separate prospecting, retargeting, and retention performance to optimize each stage independently.

## How to run it

1. Open **Meta Smart Filter** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
