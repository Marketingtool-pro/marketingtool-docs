# Facebook Ads Orchestrator

Orchestrate complex multi-campaign Facebook ad strategies from a single command center. Coordinate budget allocation, audience distribution, and creative rotation across all active campaigns.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/facebook-ads-orchestrator](https://app.marketingtool.pro/tools/facebook-ads-orchestrator)
* **iOS / Android app** — open the **Tools** tab and search “Facebook Ads Orchestrator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Campaign Strategy Description | textarea | ✅ |
| Number of Campaigns | select — 2-3, 4-6, 7-10, 10+ | optional |
| Total Monthly Budget ($) | number | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Map your funnel** — Set up campaigns for each funnel stage (awareness, consideration, conversion) with coordinated budgets.
* **Prevent overlap** — Use exclusion rules to ensure audiences don't see the same ads across multiple campaigns.
* **Balance budgets** — Allocate 60% to proven performers and 20% each to testing and scaling campaigns.

## How to run it

1. Open **Facebook Ads Orchestrator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
