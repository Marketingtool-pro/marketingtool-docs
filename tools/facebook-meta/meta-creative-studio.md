# Meta Creative Studio

AI-powered creative studio for Facebook and Instagram ads. Design, generate, and test ad creatives across all formats — Feed, Stories, Reels, Carousel — with AI-driven recommendations for visual elements and copy.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-creative-studio](https://app.marketingtool.pro/tools/meta-creative-studio)
* **iOS / Android app** — open the **Tools** tab and search “Meta Creative Studio”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Product/Brand Description | textarea | ✅ |
| Creative Format | select — Single Image (Feed), Carousel, Collection | optional |
| Creative Style | select — Lifestyle Photography, Product Showcase, User-Generated Content, Bold Typography, Minimal & Clean | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Design for format** — Create separate creatives for Feed (1:1), Stories (9:16), and Reels (9:16) — never use one size for all.
* **Test visual hooks** — The first 3 seconds determine if someone watches — test different opening frames for video ads.
* **Use AI suggestions** — Let AI recommend color schemes, text overlays, and CTA placement based on top-performing industry ads.

## How to run it

1. Open **Meta Creative Studio** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
