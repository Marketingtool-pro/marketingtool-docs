# Meta Audience Builder

Drag-and-drop Facebook audience builder that combines interests, behaviors, demographics, custom audiences, and lookalikes into precision-targeted segments. Intersect and exclude for laser-focused targeting.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-audience-builder](https://app.marketingtool.pro/tools/meta-audience-builder)
* **iOS / Android app** — open the **Tools** tab and search “Meta Audience Builder”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Target Customer Description | textarea | ✅ |
| Audience Type | select — Interest-Based, Lookalike, Custom (Retargeting), Broad (Advantage+), Hybrid | optional |
| Target Audience Size | select — Narrow (100K-500K), Medium (500K-2M), Broad (2M-10M), Very Broad (10M+) | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Intersect interests** — Narrow audiences by requiring multiple interest matches — e.g., 'fitness' AND 'online shopping' — for higher intent.
* **Layer demographics** — Add age, location, and income filters on top of interest targeting for maximum precision.
* **Test lookalike percentages** — Start with 1% lookalikes for highest quality, then test 3-5% for more scale.

## How to run it

1. Open **Meta Audience Builder** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
