# Meta Placement Optimizer

Optimize ad placements across Facebook Feed, Stories, Reels, Marketplace, Messenger, Audience Network, and Instagram. Analyze placement-level performance to allocate budget where conversions happen.

**Category:** [Facebook & Meta Ads](../facebook-meta.md) · **Badge:** Facebook/Meta

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/meta-placement-optimizer](https://app.marketingtool.pro/tools/meta-placement-optimizer)
* **iOS / Android app** — open the **Tools** tab and search “Meta Placement Optimizer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Account or Campaign ID | text | ✅ |
| Placement Strategy | select — Advantage+ (Automatic), Manual Selection, Performance Analysis, A/B Test Placements | optional |
| Platform Focus | select — Facebook + Instagram (All), Facebook Only, Instagram Only, Audience Network Included | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Creative**, **Optimize**.

## Tips for best results

* **Don't use all placements blindly** — Advantage+ placements work for some, but manual placement selection often delivers better ROI.
* **Check placement reports** — Review performance by placement weekly — Reels and Stories often have different CPA than Feed.
* **Customize by format** — Use vertical video for Stories/Reels and square images for Feed for optimal user experience.

## How to run it

1. Open **Meta Placement Optimizer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
