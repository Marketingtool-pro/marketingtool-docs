# Search Term Analyzer

Fast search term insights and recommendations. Deep analysis of your search terms report to find wasted spend, discover keyword opportunities, and build negative keyword lists.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-search-term-analysis](https://app.marketingtool.pro/tools/ppc-search-term-analysis)
* **iOS / Android app** — open the **Tools** tab and search “Search Term Analyzer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Search Terms | textarea | ✅ |
| Analysis Goal | select — Find Wasted Spend, Discover New Keywords, Build Negative Lists, Match Type Analysis, Full Analysis | ✅ |
| Monthly Search Spend ($) | number | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Wasted Spend**, **Opportunities**, **Negatives**.

## Tips for best results

* **Export Full Report** — Use 90+ days of search term data for comprehensive analysis.
* **Group by Theme** — Cluster similar search terms to spot trends and patterns.
* **Check Low-Volume Terms** — Many small wasteful queries add up to significant spend.

## How to run it

1. Open **Search Term Analyzer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
