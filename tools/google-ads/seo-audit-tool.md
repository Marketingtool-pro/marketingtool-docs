# Seo Audit Tool

Technical SEO audit for your Google Ads landing pages. Check crawlability, page speed, structured data, mobile usability, and Core Web Vitals that impact Quality Score and organic ranking.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Audit

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/seo-audit-tool](https://app.marketingtool.pro/tools/seo-audit-tool)
* **iOS / Android app** — open the **Tools** tab and search “Seo Audit Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| URLs to Audit | textarea | ✅ |
| Primary URL | text | ✅ |
| Audit Focus | select — Page Speed, Mobile Usability, Core Web Vitals, Technical SEO, Full Audit | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Scoring**, **Fixes**.

## Tips for best results

* **Fix Speed First** — Page speed impacts both QS and organic rankings.
* **Test Mobile** — Google uses mobile-first indexing—mobile experience is critical.
* **Check Core Web Vitals** — LCP, FID, and CLS directly affect user experience scores.

## How to run it

1. Open **Seo Audit Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
