# Rule Based Campaign Manager

Manage campaigns using custom IF/THEN rules. Set rules like 'IF CPA > $50 THEN reduce bid by 10%' or 'IF conversion rate > 5% THEN increase budget by 15%' for hands-free management.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Campaign

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/rule-based-campaign-manager](https://app.marketingtool.pro/tools/rule-based-campaign-manager)
* **iOS / Android app** — open the **Tools** tab and search “Rule Based Campaign Manager”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Rules to Create | textarea | ✅ |
| Rule Category | select — Bid Rules, Budget Rules, Pause/Enable Rules, Alert Rules, Combined | ✅ |
| Rule Frequency | select — Hourly, Daily, Weekly, Monthly | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Setup**, **Monitor**, **Optimize**.

## Tips for best results

* **Start with Alerts Only** — Test rules as alerts before enabling auto-actions.
* **Use Lookback Windows** — Base rules on 7-14 day averages, not single-day data.
* **Set Maximum Limits** — Always cap bid increases and budget changes for safety.

## How to run it

1. Open **Rule Based Campaign Manager** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
