# PPC Campaign Builder

The easy way to build campaigns at scale. Create large campaigns from CSV, generate thousands of ads in bulk, and manage RSAs across ad groups simultaneously.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Campaign

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-campaign-builder](https://app.marketingtool.pro/tools/ppc-campaign-builder)
* **iOS / Android app** — open the **Tools** tab and search “PPC Campaign Builder”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Campaign Brief | textarea | ✅ |
| Campaign Type | select — Search, Shopping, Display, Performance Max, Video | ✅ |
| Target Location | text | optional |
| Daily Budget ($) | number | optional |
| Keyword Match Type | select — Broad Match, Phrase Match, Exact Match, Mix of All | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Structure**, **Ads**, **Review**.

## Tips for best results

* **Start with Products** — List your products/services for automatic ad group creation.
* **Include Locations** — Specify target locations for geo-targeted campaigns.
* **Set Match Types** — Define preferred keyword match types for each ad group.

## How to run it

1. Open **PPC Campaign Builder** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
