# Google Ads Automation Rules

Save time and grow faster with intelligent Google Ads automation. Create rules to auto-pause underperformers, scale winners, adjust bids, and manage budgets based on real-time data.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/automation](https://app.marketingtool.pro/tools/automation)
* **iOS / Android app** — open the **Tools** tab and search “Google Ads Automation Rules”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| What do you want to automate? | textarea | ✅ |
| Automation Type | select — Bid Adjustments, Pause/Enable, Budget Reallocation, Alert Only, Ad Scheduling | ✅ |
| Check Frequency | select — Every Hour, Every 6 Hours, Daily, Weekly | optional |
| Performance Conditions | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Rules**, **Schedule**, **Logs**.

## Tips for best results

* **Start Conservative** — Begin with notification-only rules before enabling auto-actions.
* **Set Safety Limits** — Always set maximum bid and budget caps to prevent overspend.
* **Use Lookback Windows** — Base rules on 7-14 day averages, not single-day spikes.

## How to run it

1. Open **Google Ads Automation Rules** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
