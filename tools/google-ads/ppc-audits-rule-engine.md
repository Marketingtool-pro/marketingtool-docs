# PPC Rule Engine

Build custom audit rules that automatically flag issues in your Google Ads account. Set conditions for keywords, ads, and campaigns that trigger alerts when thresholds are breached.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-audits-rule-engine](https://app.marketingtool.pro/tools/ppc-audits-rule-engine)
* **iOS / Android app** — open the **Tools** tab and search “PPC Rule Engine”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Rule Requirements | textarea | ✅ |
| Apply To | select — Keywords, Ads, Ad Groups, Campaigns, All Levels | ✅ |
| When Triggered | select — Send Alert, Auto-Pause, Adjust Bid, Flag for Review | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Rules**, **Results**, **Schedule**.

## Tips for best results

* **Define Clear Conditions** — Use specific thresholds: CPA > $50 AND Conversions < 2.
* **Layer Multiple Rules** — Combine conditions for more precise issue detection.
* **Set Priority Levels** — Flag critical issues differently from warnings.

## How to run it

1. Open **PPC Rule Engine** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
