# Audience Optimization Tool

Optimize your Google Ads audience targeting. Analyze audience segment performance, find high-value custom segments, and refine in-market and affinity audiences for better ROAS.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** PPC Optimization

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/audience-optimization-tool](https://app.marketingtool.pro/tools/audience-optimization-tool)
* **iOS / Android app** — open the **Tools** tab and search “Audience Optimization Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Audience Strategy | textarea | ✅ |
| Audience Type | select — In-Market, Affinity, Custom Segments, Remarketing, Similar Audiences, All Types | ✅ |
| Goal | select — Find New Audiences, Optimize Existing, Reduce Wasted Spend, Scale Winners | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Performance**, **Optimize**.

## Tips for best results

* **Layer Audiences** — Combine in-market + demographics for precise targeting.
* **Use Observation Mode First** — Add audiences in observation mode to gather data before targeting.
* **Exclude Low-Value Segments** — Negative audience segments can cut wasted spend by 20-30%.

## How to run it

1. Open **Audience Optimization Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
