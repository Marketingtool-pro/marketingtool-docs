# Bid Management Tool

Smart bidding tools and faster insights. Set target CPA or ROAS, automate bid adjustments by device, location, and time of day, and maximize ROI on every click.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Budget

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-bid-management-tools](https://app.marketingtool.pro/tools/ppc-bid-management-tools)
* **iOS / Android app** — open the **Tools** tab and search “Bid Management Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Bidding Overview | textarea | ✅ |
| Bidding Strategy | select — Target CPA, Target ROAS, Maximize Conversions, Maximize Clicks, Manual CPC, Enhanced CPC | ✅ |
| Target CPA ($) | number | optional |
| Target ROAS (%) | number | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Strategy**, **Adjustments**, **Results**.

## Tips for best results

* **Set Target CPA/ROAS** — Define your target metrics before adjusting bids.
* **Analyze by Device** — Mobile, desktop, and tablet often need different bids.
* **Check Auction Insights** — Know your competitors' impression share before bidding up.

## How to run it

1. Open **Bid Management Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
