# Keyword Analysis Tool

Fast keyword insights and recommendations. Analyze keyword performance, find cannibalization issues, discover expansion opportunities, and optimize match type distribution.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-keyword-analysis-tool](https://app.marketingtool.pro/tools/ppc-keyword-analysis-tool)
* **iOS / Android app** — open the **Tools** tab and search “Keyword Analysis Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Keywords to Analyze | textarea | ✅ |
| Analysis Type | select — Performance Review, Keyword Cannibalization, New Opportunities, Negative Keyword Mining, Match Type Analysis | ✅ |
| Industry | text | optional |
| Target CPA ($) | number | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Performance**, **Gaps**, **Expand**.

## Tips for best results

* **Export Keywords** — Share your keyword list with match types and metrics.
* **Include Search Terms** — Add search term data for real query analysis.
* **Set Conversion Window** — Use 30+ day data for accurate conversion attribution.

## How to run it

1. Open **Keyword Analysis Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
