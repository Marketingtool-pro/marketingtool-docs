# Scientific Ad Testing

Statistically rigorous ad testing using Bayesian analysis. Multi-metric performance measurement beyond simple CTR—measure lift in conversions and revenue per impression.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/scientific-ad-testing](https://app.marketingtool.pro/tools/scientific-ad-testing)
* **iOS / Android app** — open the **Tools** tab and search “Scientific Ad Testing”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Test Setup | textarea | ✅ |
| Primary Metric | select — Click-Through Rate, Conversion Rate, Cost Per Conversion, Revenue Per Impression, Multi-Metric | ✅ |
| Confidence Level | select — 90%, 95%, 99% | optional |
| Control Ad Headline | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Test Setup**, **Results**, **Winner**.

## Tips for best results

* **Define Success Metric** — Choose one primary metric: CTR, conversion rate, or CPI.
* **Run to Significance** — Don't stop tests early—wait for 95%+ confidence level.
* **Test Meaningful Differences** — Test different value props, not just word swaps.

## How to run it

1. Open **Scientific Ad Testing** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
