# Smart Bidding Optimizer

Smart bidding tools with faster insights for Google Ads. Optimize Smart Bidding strategies, analyze conversion lag, and fine-tune Target CPA/ROAS for maximum efficiency.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Budget

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/ppc-bidding-tools](https://app.marketingtool.pro/tools/ppc-bidding-tools)
* **iOS / Android app** — open the **Tools** tab and search “Smart Bidding Optimizer”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Current Bidding Setup | textarea | ✅ |
| Primary Conversion | text | ✅ |
| Average Conversion Lag | select — Same Day, 1-3 Days, 3-7 Days, 7-14 Days, 14+ Days | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Recommendations**, **Apply**.

## Tips for best results

* **Wait for Learning** — Smart Bidding needs 2-4 weeks of data to optimize properly.
* **Check Conversion Lag** — Account for delayed conversions when evaluating performance.
* **Use Portfolio Strategies** — Group similar campaigns under one portfolio bid strategy.

## How to run it

1. Open **Smart Bidding Optimizer** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
