# Campaign Tools Suite

Complete toolkit for Google Ads campaign management. Create, optimize, and scale campaigns with bulk editing, automated rules, performance tracking, and competitive analysis in one place.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Campaign

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/campaign-tools-suite](https://app.marketingtool.pro/tools/campaign-tools-suite)
* **iOS / Android app** — open the **Tools** tab and search “Campaign Tools Suite”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| What do you need? | textarea | ✅ |
| Primary Action | select — Create New Campaign, Optimize Existing, Bulk Edit, Generate Reports, Competitive Analysis | ✅ |
| Account Size | select — Small (1-5 campaigns), Medium (5-20), Large (20-50), Enterprise (50+) | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Setup**, **Monitor**, **Optimize**.

## Tips for best results

* **Use Bulk Operations** — Save hours by making changes across campaigns simultaneously.
* **Set Up Automation** — Automate repetitive tasks like bid adjustments and reporting.
* **Monitor Competitors** — Track competitor activity in Auction Insights weekly.

## How to run it

1. Open **Campaign Tools Suite** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
