# Keyword Audit Tool

Audit your keyword portfolio for wasted spend, cannibalization, and missed opportunities. Find keywords with high cost but no conversions, overlapping keywords, and Quality Score issues.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Audit

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/keyword-audit-tool](https://app.marketingtool.pro/tools/keyword-audit-tool)
* **iOS / Android app** — open the **Tools** tab and search “Keyword Audit Tool”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Keywords to Audit | textarea | ✅ |
| Audit Priority | select — Wasted Spend, Keyword Cannibalization, Quality Score Issues, Match Type Review, Full Keyword Audit | ✅ |
| Data Period | select — Last 30 Days, Last 90 Days, Last 6 Months, Last Year | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Scoring**, **Fixes**.

## Tips for best results

* **Export Full Keyword List** — Include all keywords—even paused ones—for a complete audit.
* **Include Search Terms** — Search term data reveals real queries triggering your keywords.
* **Check for Duplicates** — Duplicate keywords across ad groups cannibalize each other.

## How to run it

1. Open **Keyword Audit Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
