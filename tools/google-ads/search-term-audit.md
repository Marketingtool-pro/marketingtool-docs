# Search Term Audit

Audit your search terms report to find wasted spend and new opportunities. Identify irrelevant queries costing you money, discover new keyword ideas, and build negative keyword lists.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Audit

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/search-term-audit](https://app.marketingtool.pro/tools/search-term-audit)
* **iOS / Android app** — open the **Tools** tab and search “Search Term Audit”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Search Terms Data | textarea | ✅ |
| Audit Goal | select — Find Wasted Spend, Discover New Keywords, Build Negative Lists, Match Type Analysis, Full Audit | ✅ |
| Data Period | select — Last 30 Days, Last 90 Days, Last 6 Months | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Scoring**, **Fixes**.

## Tips for best results

* **Sort by Cost** — Start with the highest-cost search terms to find biggest waste.
* **Check Zero-Conversion Terms** — Terms with 10+ clicks and zero conversions are likely waste.
* **Group by Theme** — Cluster related terms to spot patterns and build negative lists.

## How to run it

1. Open **Search Term Audit** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
