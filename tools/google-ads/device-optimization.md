# Device Optimization

Optimize your Google Ads performance by device type. Analyze mobile vs desktop vs tablet performance and set device bid adjustments to maximize conversions on each platform.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** PPC Optimization

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/device-optimization](https://app.marketingtool.pro/tools/device-optimization)
* **iOS / Android app** — open the **Tools** tab and search “Device Optimization”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Device Performance Data | textarea | ✅ |
| Primary Device Issue | select — Mobile CPA Too High, Desktop Converting Better, Tablet Wasting Spend, Need Device Strategy, Full Analysis | ✅ |
| Industry | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Targeting**, **Performance**, **Optimize**.

## Tips for best results

* **Check Mobile Landing Pages** — Slow mobile pages kill conversion rates—test speed first.
* **Consider User Intent** — Mobile users often research; desktop users often buy.
* **Bid Down on Tablets** — Tablets rarely convert well—start with -30% bid adjustment.

## How to run it

1. Open **Device Optimization** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
