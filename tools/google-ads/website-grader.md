# Website Grader

Grade your website's performance for Google Ads and organic search. Check page speed, SEO health, mobile experience, security, and conversion readiness with a comprehensive score.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Grader

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/website-grader](https://app.marketingtool.pro/tools/website-grader)
* **iOS / Android app** — open the **Tools** tab and search “Website Grader”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Website URL | textarea | ✅ |
| Website URL | text | ✅ |
| Grade Focus | select — Overall Performance, Speed & Performance, SEO Health, Mobile Experience, Security & SSL, Conversion Readiness | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Scoring**, **Fixes**.

## Tips for best results

* **Test Key Landing Pages** — Grade each landing page individually, not just the homepage.
* **Compare to Competitors** — Grade competitor sites to benchmark your performance.
* **Fix Critical Issues First** — Focus on red flags before optimizing yellow warnings.

## How to run it

1. Open **Website Grader** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
