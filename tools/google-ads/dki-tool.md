# Dynamic Keyword Insertion Tool

Master Dynamic Keyword Insertion (DKI) in Google Ads. Generate DKI-enabled ad copy, test fallback text, and learn when DKI helps vs hurts your campaign performance.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Google Ads

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/dki-tool](https://app.marketingtool.pro/tools/dki-tool)

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Ad Copy with DKI | textarea | ✅ |
| Keywords to Test | text | ✅ |
| Default Fallback Text | text | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Generate**, **Preview**, **Best Practices**.

## Tips for best results

* **Always Set Fallback Text** — DKI needs a default when keyword is too long for the headline.
* **Watch for Awkward Queries** — DKI can insert competitor names or misspellings into your ads.
* **Use in Headlines Only** — DKI in headlines boosts relevance; in descriptions it often looks odd.

## How to run it

1. Open **Dynamic Keyword Insertion Tool** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
