# Google Analytics Grader

Audit your Google Analytics setup and configuration. Check tracking code installation, goal setup, event tracking, conversion attribution, and data accuracy to ensure reliable reporting.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Grader

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/google-analytics-grader](https://app.marketingtool.pro/tools/google-analytics-grader)
* **iOS / Android app** — open the **Tools** tab and search “Google Analytics Grader”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Analytics Setup Details | textarea | ✅ |
| Analytics Version | select — GA4, Universal Analytics, Both, Not Sure | ✅ |
| Audit Focus | select — Tracking Setup, Goal Configuration, Event Tracking, Attribution, Full Audit | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Analysis**, **Scoring**, **Fixes**.

## Tips for best results

* **Check Tag Firing** — Use Google Tag Assistant to verify tags fire on every page.
* **Verify Conversions** — Compare GA conversions with actual sales/leads for accuracy.
* **Link Google Ads** — GA4 to Google Ads linking enables audience sharing and ROAS.

## How to run it

1. Open **Google Analytics Grader** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
