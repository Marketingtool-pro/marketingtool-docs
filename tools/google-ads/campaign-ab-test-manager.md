# Campaign Ab Test Manager

Set up and manage A/B tests across your Google Ads campaigns. Test bidding strategies, ad copy, landing pages, and audiences with proper experiment controls and statistical rigor.

**Category:** [Google Ads & PPC](../google-ads.md) · **Badge:** Campaign

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/campaign-ab-test-manager](https://app.marketingtool.pro/tools/campaign-ab-test-manager)
* **iOS / Android app** — open the **Tools** tab and search “Campaign Ab Test Manager”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Test Plan | textarea | ✅ |
| Test Type | select — Bid Strategy, Ad Copy, Landing Page, Audience Segments, Campaign Settings | ✅ |
| Test Duration | select — 2 Weeks, 4 Weeks, 6 Weeks, 8 Weeks | optional |
| Traffic Split | select — 50/50, 70/30, 80/20 | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Setup**, **Monitor**, **Optimize**.

## Tips for best results

* **Test One Variable** — Change only one thing at a time for clear, actionable results.
* **Run for 4+ Weeks** — Short tests don't account for weekly performance cycles.
* **Need 100+ Conversions** — Each variant needs sufficient conversions for statistical validity.

## How to run it

1. Open **Campaign Ab Test Manager** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
