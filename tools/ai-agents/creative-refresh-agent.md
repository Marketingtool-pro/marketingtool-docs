# Creative Refresh Agent

Automated creative refresh agent that monitors ad fatigue signals and generates new creative variations when performance starts declining. Keep your Facebook and Instagram ads fresh without manual intervention.

**Category:** [AI Agents & Automation](../ai-agents.md) · **Badge:** Creative

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/creative-refresh-agent](https://app.marketingtool.pro/tools/creative-refresh-agent)
* **iOS / Android app** — open the **Tools** tab and search “Creative Refresh Agent”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Campaign or Ad Set to Monitor | textarea | ✅ |
| Refresh Trigger | select — CTR drops 20%, Frequency exceeds 3x, CPA increases 30%, Engagement drops 25%, Custom threshold | optional |
| Refresh Action | select — Generate new variations, Rotate existing creatives, Suggest refresh only (manual), Auto-replace lowest performer | optional |

## Result workspace

Your result page is organized into tabs: **Overview**, **Create**, **Library**, **Optimize**.

## Tips for best results

* **Set auto-refresh rules** — Configure rules like 'refresh when CTR drops 20% from peak' for hands-free creative management.
* **Pre-approve templates** — Create approved creative templates so the agent can generate new variations within your brand guidelines.
* **Stagger refreshes** — Rotate creatives across ad sets at different times to avoid performance dips across all campaigns.

## How to run it

1. Open **Creative Refresh Agent** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
