# Workflow Automation Builder

AI-powered workflow automation builder.

**Category:** [AI Agents & Automation](../ai-agents.md) · **Badge:** Automation

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/workflow-automation-builder](https://app.marketingtool.pro/tools/workflow-automation-builder)
* **iOS / Android app** — open the **Tools** tab and search “Workflow Automation Builder”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |

## Result workspace

Your result page is organized into tabs: **Overview**, **Build**, **Triggers**, **Logs**.

## Tips for best results

* **Describe the Process** — Explain the workflow you want to automate.
* **Set Triggers** — Define what events should start the automation.
* **Define Actions** — List what should happen when triggered.

## How to run it

1. Open **Workflow Automation Builder** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
