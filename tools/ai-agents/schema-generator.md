# Schema Generator

AI-powered schema generator.

**Category:** [AI Agents & Automation](../ai-agents.md) · **Badge:** Schema

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/schema-generator](https://app.marketingtool.pro/tools/schema-generator)
* **iOS / Android app** — open the **Tools** tab and search “Schema Generator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Schema Type | select — Article, Product, LocalBusiness, FAQ, HowTo, Event | ✅ |
| Page URL | text | ✅ |
| Details | textarea | ✅ |

## Result workspace

Your result page is organized into tabs: **Overview**, **Writing**, **Editing**, **Publish**.

## Tips for best results

* **Include Target URL** — Provide the page URL for specific analysis.
* **Add Keywords** — List your primary and secondary target keywords.
* **Mention Competitors** — Name competitors for comparison insights.

## How to run it

1. Open **Schema Generator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
