# Api Documentation Generator

AI-powered api documentation generator.

**Category:** [AI Agents & Automation](../ai-agents.md) · **Badge:** Developer

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/api-documentation-generator](https://app.marketingtool.pro/tools/api-documentation-generator)
* **iOS / Android app** — open the **Tools** tab and search “Api Documentation Generator”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |

## Result workspace

Your result page is organized into tabs: **Overview**, **Writing**, **Editing**, **Publish**.

## Tips for best results

* **Paste Your Code** — Include the actual code for accurate documentation.
* **Specify Language** — Name the programming language used.
* **Define Audience** — Is this for developers, users, or both?

## How to run it

1. Open **Api Documentation Generator** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
