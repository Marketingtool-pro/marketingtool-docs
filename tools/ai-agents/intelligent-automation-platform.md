# Intelligent Automation Platform

AI-powered intelligent automation platform.

**Category:** [AI Agents & Automation](../ai-agents.md) · **Badge:** AI Agent

## Where to find it

* **Web app** — [app.marketingtool.pro/tools/intelligent-automation-platform](https://app.marketingtool.pro/tools/intelligent-automation-platform)
* **iOS / Android app** — open the **Tools** tab and search “Intelligent Automation Platform”

## Inputs

| Input | Type | Required |
| --- | --- | --- |
| Describe what you need | textarea | ✅ |

## Result workspace

Your result page is organized into tabs: **Overview**, **Build**, **Triggers**, **Logs**.

## Tips for best results

* **Describe the Process** — Explain the workflow you want to automate.
* **Set Triggers** — Define what events should start the automation.
* **Define Actions** — List what should happen when triggered.

## How to run it

1. Open **Intelligent Automation Platform** (links above).
2. Fill in the inputs and press **Generate**.
3. Review your full result page — it's saved to your History automatically. On desktop, use **Download All** to save every asset.
