# Create an account

## Sign-up options

* **Email + one-time code (OTP)** — enter your email and we send you a 6-digit code. No password to remember.
* **OAuth providers** — sign in with Google, Apple, and other supported providers.

The same account works across the web app and both mobile apps — sign in anywhere and your history, credits, and plan follow you.

## Troubleshooting sign-in

* **Didn't get the code?** Check spam, then request a new code. Codes expire after a few minutes.
* **"API key expired" or similar errors on Android** — update to the latest app version and try again; if it persists, contact [Help@marketingtool.pro](mailto:Help@marketingtool.pro).
* **Switching devices** — just sign in with the same email; nothing is lost.
